Star Schema Architecture

5-table normalized data model replacing the legacy flat table

Row ID (PK) Order ID OrderDateKey (FK) ShipDateKey (FK) Customer ID (FK) Product ID (FK) GeographyKey (FK) Sales, Profit, Quantity, Discount
Dim_Date (1,468 Rows)
DateKey, Date, Year, Quarter, Month, Year_Month
Dim_Customer (1,590 Rows)
Customer ID, Name, Segment, RFM Tier
Dim_Product (10,292 Rows)
Product ID, Name, Category, Sub-Category
Dim_Geography (3,819 Rows)
GeographyKey, Country, City, Region, Market

Enterprise DAX Measures Library

Production DAX formulas with Time Intelligence & Margin calculations

[Total Sales] = SUM(Fact_Orders[Sales])

[Total Profit] = SUM(Fact_Orders[Profit])

[Profit Margin %] = DIVIDE([Total Profit], [Total Sales], 0)

[Average Discount %] = AVERAGE(Fact_Orders[Discount])
// Replaces mathematically invalid SUM(Discount)

[Sales YoY Growth %] = 
DIVIDE(
    [Total Sales] - CALCULATE([Total Sales], SAMEPERIODLASTYEAR(Dim_Date[Date])),
    CALCULATE([Total Sales], SAMEPERIODLASTYEAR(Dim_Date[Date])),
    0
)

[Loss Making Orders Count] = 
CALCULATE(
    DISTINCTCOUNT(Fact_Orders[Order ID]),
    Fact_Orders[Profit] < 0
)

[Top 10 Products Filter] = 
IF(
    RANKX(ALLSELECTED(Dim_Product[Product_Name]), [Total Sales], , DESC, Dense) <= 10,
    1, 
    0
)
